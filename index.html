Understand the terms. Explore with confidence.

The essentials

Ticker
An asset’s short symbol, such as BTC for Bitcoin.
USD price
The price of one unit in US dollars. An API quote is a last-trade snapshot.
24-hour volume
The amount traded over a day. Check its unit; volume is different from price.
Price change
How much a price moved over a period, often a percentage. This page does not report it.
Market timestamp
When the provider observed a quote. Receiving a response now does not make an old quote current.

Your questions, answered

Are these prices live?

Check the label beside the asset. Sample data is fixed for demonstration. API data comes through Flask; its market timestamp determines whether freshness can be checked. The selected asset refreshes every 30 seconds while this tab is visible.

Why is information missing?

The database or market API may not supply every field. Missing descriptions, categories, quotes and units are marked explicitly. Sample values never fill gaps in an API response.

How do I get another quote?

The selected asset refreshes on page load and every 30 seconds while this tab is visible. You can also refresh it manually. Requests pause during cooldowns or API rate limits. Sample values stay fixed.

Which assets can I explore?

The catalog contains 27 assets. In API mode, assets awaiting database support are marked unavailable. Monero is excluded because its configured Coinbase USD market is unavailable.

Where can I view JSON?

Open Specifications in the asset overview, then View JSON response. With the supplied Flask API, database and market responses are combined in the browser, with links to both original endpoints.

Where is my watchlist saved?

Your watchlist is saved in this browser on this device. It does not create an account or sync between devices. If browser storage is unavailable, it lasts for this visit.
