# Coin logo sources

All 27 coin logos are bundled locally as SVG files. The interface does not depend on a remote image host. These are existing brand marks from [Web3 Icons](https://github.com/0xa3k5/web3icons), not generated images or letter substitutes.

The files are unmodified `packages/core/src/svgs/tokens/background/<SYMBOL>.svg` icons from revision [`e6d3c8f6adcfa04bb76bb6a871556a8e7589862e`](https://github.com/0xa3k5/web3icons/tree/e6d3c8f6adcfa04bb76bb6a871556a8e7589862e). They retain their source colors and paths; the website supplies only their displayed size and circular clipping.
